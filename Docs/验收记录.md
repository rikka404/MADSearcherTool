## 4. 已说明的功能边界

- PSD图层/钢笔路径序列按设计暂不实现；当前提供透明PNG、mask、MOV和AE路径交接。
- SAM分割以可人工修补的初稿为目标；首帧以外alpha为二值，不保证发丝、运动模糊、透明特效和遮挡处的精细抠像。
- 抠像上限120秒、3600帧，按源解码帧号保留选中范围并以平均帧率输出；抠像MOV和棋盘预览不含音轨。默认32帧分块可能产生衔接误差。
- AE路径是二值轮廓近似，受轮廓数、顶点数和帧率限制；复杂输出会提示AE未导出，并保留像素序列。
- 无视觉分析的字幕索引无法完整检索纯画面场景；查询分数不等于命中概率。

上述边界在[使用说明](使用说明.md)和[抠像边界](抠像边界.md)中有具体输入要求与处理方法。交付节点完成表示当前约定的实现和文档已交付，不表示延期验收已经通过。
