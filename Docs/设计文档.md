# MADSearcher 设计文档

版本1；先确定合同与边界，随后按DAG开发。所有相对路径以仓库根目录为基准。

## 1. 结构

`src/MADSearcher.Desktop/`：WPF窗口、状态、输入校验、Python进程客户端。
`worker/mad_worker/`：CLI、媒体核心、素材库检索、抠像及输出。
`tests/`：核心逻辑和真实FFmpeg集成测试；不依赖用户私有素材。
`scripts/`：安装、启动、发布、DAG校验及状态工具。
`Docs/`：方案、设计、协议、验收与使用说明。
`.agents/skills/`：本项目真实复现问题的恢复经验。

运行时的 `workspace/`、`.venv/`、`models/`、`artifacts/` 不入Git。默认全在项目目录，原素材只读。

### 命令行补充设计（按新增需求）

`scripts/cli.py` / `MADSearcher-CLI.cmd` 提供与worker命令同名的参数化入口，例如 `group.create --name MyGO`、`search.run --group-id ID --query 祥子`。全部核心命令共用原有处理模块与校验，不另写检索或模型逻辑。每条命令支持 `--params-file` 读取JSON参数；`request --request-file 文件` 接受完整原始请求，`-` 表示stdin。stdout仍为NDJSON，进度/结果/错误语义不变。

CLI 默认读取GUI普通设置，支持独立 `--settings` JSON及命令参数覆盖；密钥只从本次 `OPENAI_API_KEY` 环境变量或显式stdin请求取得，不提供会进入进程列表的 `--api-key` 参数，不将key写入文件。普通设置文件中的key不加载。Ctrl+C中断当前处理。新增 `ae.send` 服务仅验证路径并把已生成JSX交给 `AfterFX.exe -r`；结果明确区分已派发与AE执行完成。AE动作只有用户显式调用该命令时执行，当前不测试此动作。

## 2. 进程协议（模块间合同）

执行 `python -u -m mad_worker`，工作目录为 `worker/`。stdin只有一行JSON后关闭；stdout每行一个事件；第三方输出必须导向stderr。请求包含：

```json
{"command":"group.list","params":{},"settings":{},"workspace":"E:/MADSearcher/MADSearcherTool/workspace"}
```

事件：`{"type":"progress","progress":0.5,"message":"说明"}`、`{"type":"result","data":{}}` 或 `{"type":"error","code":"validation","message":"中文可操作说明"}`。进程退出0对应成功；非零失败。取消由父进程终止整个子进程树，UI保持响应。无命令行key，无日志回显key。

统一 settings：`ffmpeg_path`、`ffprobe_path`（默认命令名）；`api_key`（空）、`vision_model`（gpt-4.1-mini）、`embedding_model`（text-embedding-3-small）；`sam_checkpoint`（空）、`sam_config`（configs/sam2.1/sam2.1_hiera_t.yaml）、`device`（cpu/cuda）；`whisper_model`（small）、`whisper_device`（cpu）。WPF本地设置另含 `python_path` 和 `workspace`。

Python共享 `Context`：`workspace: Path`、`settings: dict`、`media: Media`、`progress(value,message)`；业务异常 `UserError(message, code="validation")`。所有模块入口 `handle(command, params, ctx) -> dict`。

媒体合同 `Media(settings)`：`probe(path)->{path,duration,width,height,fps,has_audio}`；`extract_frame(path,seconds,output)->str`；`extract_frames(path,start,end,fps,directory)->list[Path]`；`make_preview(path,start,end,output)->str`；`run(args,timeout=...)->CompletedProcess`（args为ffmpeg开关，方法自动前置ffmpeg）；FFmpeg数组参数，禁shell拼接。

| command | params | result.data |
| --- | --- | --- |
| system.check | 无 | checks数组（name,ok,message），python版本 |
| group.list | 无 | groups:[{id,name,description,video_count,segment_count}] |
| group.create | name,description | group对象 |
| group.update | group_id,name,description | group对象 |
| group.delete | group_id | deleted:true（仅库记录） |
| video.list | group_id | videos:[{id,path,name,duration,width,height,fps,status,subtitle_path}] |
| video.add | group_id,paths:[] | videos数组，warnings数组（重复提示） |
| video.remove | video_id | deleted:true（仅库记录） |
| index.run | video_id,subtitle_path可空,subtitle_offset:0,transcribe:false,language:"auto",visual:false,semantic:false,segment_seconds:8 | segment_count,video_id,mode,warnings |
| search.run | group_id,query,limit:20,semantic:false | results:[{video_id,path,name,start,end,text,score,thumbnail,match_type}],warnings |
| video.probe | path | 媒体元数据 |
| video.frame | path,time:0 | path（缓存PNG）,width,height |
| preview.make | path,start,end | path（缓存H264 MP4） |
| clip.export | path,start,end,output_dir | path（独立MP4） |
| cutout.run | path,start,end,prompt_mode:mask/text/reference/box,mask_path,prompt,reference_path,box:[x0,y0,x1,y1],output_dir,export_video:true,export_ae:true | output_dir,frame_count,fps,preview_path,rgba_dir,mask_dir,video_path,ae_script,manifest_path,warnings |
| ae.send | script_path；settings.afterfx_path | dispatched,pid,script_path,message（仅确认派发） |

box为首帧原图像素坐标；mask是所选片段首帧对应的同尺寸透明PNG或黑白图。text和reference要求key，mask和box完全本地。字幕index先解析整个文件并按真实时间聚合，ASR仅无外挂字幕且用户勾选时执行。GUI可以批量逐视频索引，单个请求只负责一个视频。索引仅在 `visual` 或 `semantic` 明确开启时调用 OpenAI；仅填写密钥不会触发云端处理。视觉索引同时建立向量，字幕语义索引仅发送文字。`video.list` 从已保存索引配置返回 `subtitle_offset`。

## 3. 用户界面

遵循需求草图：顶部通用菜单和项目状态，左侧“片段检索”“自动抠像”，左下设置，右侧功能工具条与主区。中文界面，深色中性底、青绿色强调，明确空状态和步骤提示。

检索页：分组选择/新建/编辑；素材列表批量导入与选中；字幕绑定、字幕偏移、ASR语言和视觉索引选择；索引进度/取消；查询框和语义开关；结果卡片（缩略图、原文件、时间、命中说明）；预览播放器、起止可调、导出片段或送抠像。

抠像页：视频选择与探测；起止秒；首帧查看；模式选择；蒙版/描述/参考图输入；可选像素框；导出目录、MOV/AE选项；运行进度和可取消；结果预览、打开输出文件夹。PSD明确“暂不支持”。没有可用SAM checkpoint时给出安装指引，不执行空任务。

设置：Python/FFmpeg路径、运行目录、OpenAI密码框和模型、SAM权重及配置、CPU/CUDA、Whisper模型；环境诊断；保存普通设置，密钥不持久化。

## 4. 数据与一致性

SQLite外键约束groups→videos→segments。原路径规范化后同组唯一，视频文件大小和mtime作为变化探针。字幕/模型配置变更需要重新索引。索引失败显示失败原因、保留上一次可用数据，不能把一半结果标记完成。按group_id过滤每次搜索，无全库混搜。结果同视频邻接片段适度合并，时间裁到[0,duration]。缩略图与预览缓存均由内部生成的名称定位。

字幕台词词法检索为无key的实用基础；语义搜索要有已建向量，缺失时显示降级原因。不要把substring冒充AI。人物姓名依赖字幕和分组上下文，模型不确定时保留外观描述。

抠像任务单独目录，先写中间产物，完成时写manifest。manifest记录原视频、起止、fps、尺寸、模型、输出与警告，不含key。逐帧时序以统一fps重采样，源VFR转换为CFR并提示；不称其为原生VFR无损帧映射。默认短片段，上限120秒/3600帧，SAM2默认32帧一块，以重叠首帧蒙版衔接，释放块状态，CPU缓存帧。分块会有时序边界误差，输出中明示。轮廓导出是像素mask近似，采用HOLD关键帧避免不同顶点数的插值错误；复杂孔洞与遮挡处理需验证，PNG为最终像素依据。

## 5. 校验与错误

GUI和worker均校验：空名称、重复分组、未选素材、不存在/无视频流/损坏文件、非有限时间、end≤start、越界时间、超长任务、蒙版尺寸与前景为空/全画面、输出目录可写且不覆盖输入、缺权重、缺依赖、未配key、未知模式/命令。禁止用户继续非法步骤；worker错误为具体修复说明。按钮在运行中禁用重复提交；取消终止子进程，旧索引和原文件不变。所有数值采用InvariantCulture传输。

## 6. 验收

先测协议/输入/真实媒体，再独立测分组隔离、字幕偏移、多语内容、失败恢复、clip边界/缩略图；分割用短合成动画+首帧mask和真实SAM权重验证帧数、透明alpha与AE脚本。OpenAI与ASR使用可控响应合同测试，真实外部调用未配置时明确标为未验证。WPF编译并实际启动，检查布局、首屏、状态与缺依赖提示；生成可运行发布目录。最后更新DAG、验收记录和使用说明。
