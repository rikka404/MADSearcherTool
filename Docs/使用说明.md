# MADSearcher 使用说明

版本：1.0.0。项目目录：`E:\MADSearcher\MADSearcherTool`。

本工具提供两个核心流程：从大量动画素材中定位镜头，以及将短片段中的人物分离为透明素材。它不替代剪辑软件，也不自动完成一支 MAD。当前按照用户要求暂停新增及回归测试，以下说明依据已实现的接口与界面编写；验收状态见[验收记录](验收记录.md)。

## 1. 安装与启动

### 当前电脑

已在项目内准备 `.venv`、SAM 2.1 tiny 权重和 CUDA 版 PyTorch。直接打开：

```text
E:\MADSearcher\MADSearcherTool\artifacts\app\MADSearcher.exe
```

也可双击 `MADSearcher.cmd`。此入口会执行 Release 编译，需要 .NET SDK；直接运行已发布 EXE 只需要对应的 .NET Desktop Runtime。发布目录依赖项目中的 `worker`、`.venv` 和模型文件，不能只复制一个 EXE 到别处。

### 新电脑或重新准备环境

先安装 Windows 版 .NET 9 SDK、Python 3.10 或更高版本，以及 FFmpeg / FFprobe。当前实现验证过的 Python 基线是 3.10，模型依赖在不同 Python 版本上仍需兼容的 wheel。

在 PowerShell 中进入项目：

```powershell
Set-Location 'E:\MADSearcher\MADSearcherTool'
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\setup.ps1
```

上面只准备基础依赖并编译界面。按需要增加组件：

```powershell
# SAM + NVIDIA GPU 推理
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\setup.ps1 -WithSam -Cuda

# SAM CPU 推理及本地多语言转录
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\setup.ps1 -WithSam -WithWhisper
```

| 参数 | 含义 |
| --- | --- |
| `-WithSam` | 安装 PyTorch、SAM 2 和官方 tiny 权重；下载量较大 |
| `-Cuda` | 与 `-WithSam` 合用，选择 CUDA 12.4 版 PyTorch；需要 NVIDIA GPU 与兼容驱动 |
| `-WithWhisper` | 安装 faster-whisper；语音模型在首次转录时下载 |
| `-Python '完整路径\python.exe'` | 指定用于创建虚拟环境的 Python |
| `-Direct` | 本次安装进程使用直连；适用于本机代理失效，不修改全局代理配置 |

安装目录默认都在项目中。`.venv`、`models`、`workspace`、`artifacts` 不提交到 Git。当前本机 CUDA wheel 约 2.5 GB，SAM tiny 权重约 156 MB，安装及视频帧缓存还需额外磁盘空间。

## 2. 首次设置

点击左下角“设置与环境”：

| 设置 | 建议或用途 |
| --- | --- |
| Python | `E:\MADSearcher\MADSearcherTool\.venv\Scripts\python.exe`；本机存在时自动选用 |
| FFmpeg / FFprobe | 可填 PATH 中的命令名，或对应 `.exe` 的完整路径 |
| 工作区 | 默认项目下 `workspace`；桌面端要求位于项目目录内 |
| API Key | 默认空；在密码框填写后点击“保存设置”，以明文保存在本地，重启后自动恢复 |
| 视觉模型 | 默认 `gpt-4.1-mini`；需账号实际拥有该模型权限 |
| Embedding 模型 | 默认 `text-embedding-3-small`；更换后应重新建立向量索引 |
| SAM 权重 | `models\sam2.1_hiera_tiny.pt` 的完整路径 |
| SAM 配置 | tiny 对应 `configs/sam2.1/sam2.1_hiera_t.yaml` |
| SAM 计算设备 | 本机 RTX 3060 已准备 CUDA 环境，可选择 `cuda`；不支持 GPU 时选择 `cpu` |
| Whisper 模型 / 设备 | 默认 `small` / `cpu`；可填写已下载的模型目录，CUDA 转录另需兼容的 cuDNN/cuBLAS 环境 |
| After Effects | 需要直接交接时填写安装目录中的 `AfterFX.exe` 完整路径 |

点击“保存设置”。设置与API Key保存在项目的 `workspace/settings.json`，该目录已被Git忽略。清空密码框后再次保存即可删除已保存的key。环境诊断用于显示依赖状态，密钥存在不代表 API 权限或余额已验证。

仅填写密钥不会自动发送素材。以下操作会调用 OpenAI：AI画面分析、字幕语义索引、语义查询、文字/参考图定位。它们会发送采样图或文字，不上传整集原视频；API费用由所填密钥的账户承担。

## 3. 找镜头

### 创建分组并导入

1. 打开“片段检索”，在素材库点击“新建”，每部动画建立一个分组。
2. 分组说明可写角色全名、别名、外观特征和作品背景，帮助视觉模型描述素材。仅有说明并不能让纯字幕索引自动识别人脸或画面中的人物。
3. 点击“导入 MP4”，可一次选多个文件。程序引用原路径，不复制或改写原片；同组的重复路径会跳过。
4. 选中一个素材，再配置它的字幕与索引选项。

### 选择索引方式

| 方式 | 能力 | 依赖 |
| --- | --- | --- |
| 外挂字幕关键词 | 找字幕中出现的台词、名字和文字线索 | SRT / ASS / VTT；不需要 API key |
| 本地语音识别 | 没有字幕时生成带时间轴的原语文字 | faster-whisper 和语音模型 |
| 建立字幕语义索引 | 对字幕建立语义向量，支持近义或跨语言线索 | 显式勾选该选项及 OpenAI key |
| AI分析画面与情节 | 对每段多张采样图建立描述，同时生成语义向量 | 显式勾选该选项及 OpenAI key |

外挂字幕必须与当前选中的素材对应。正的“字幕偏移”让字幕向后推迟，负数提前；单位为秒。当前素材保存成功的索引配置会记住字幕路径和偏移。字幕必须有有效时间轴；允许起止时间相等，零时长台词按该时间点归入对应索引窗口。乱码、倒置时间和完全越界会给出提示。

若无字幕，可勾选本地语音识别并选择“自动”、日语、中文等语言。首次运行可能下载模型。若同时提供外挂字幕和勾选转录，程序优先使用外挂字幕。角色名字、歌词和背景音乐处的转录仍需核对。

点击“建立 / 更新选中素材索引”。桌面端按约8秒窗口索引；索引完成后可重复查询，不必每次重新分析。CLI可用 `--segment-seconds` 调整窗口（2–60秒）。窗口越短，需要处理的片段越多。

“索引组内全部素材”逐个处理本组视频：选中素材使用当前表单，其他素材使用各自已保存的字幕路径和偏移，AI及转录选项沿用当前勾选状态。没有字幕又未选择转录/画面分析的素材会被阻止；建议先为各集分别绑定字幕。

### 查询与预览

输入“祥子”“电车”“乐队”“在车站等人”等关键词。查询只在当前分组内进行。勾选“语义检索”时会请求查询向量；相应素材须已建立语义或视觉索引。普通关键词检索也能查找已保存的视觉描述。

结果会显示文件名、起止时间、缩略图和命中文字/描述，卡片列表按像素连续滚动。仅字幕索引查不到画面中没有被字幕提及的电车或人物，是能力边界，不代表原片没有相应镜头。未知角色、复杂情节和短暂闪现也可能漏检。

选中结果后点击“生成 / 更新预览”。可修改起止秒数、重新预览、导出 MP4，或“送到自动抠像”。预览会转成便于播放的 H.264 MP4，源视频为10bit H.264等编码时尤其有用。单次预览最长5分钟。生成的预览是缓存文件，不改变原片。

取消会停止当前处理；重做索引只有全部成功后才替换数据库中的旧索引。原视频、字幕或分组说明改变后，旧索引会被标为需要更新并从查询中跳过。

### 任务进行时的操作

索引、检索、转码或抠像进行时，可以切换页面、滚动、选择现有素材和结果、播放已有预览、编辑其他表单及保存设置。新增处理任务的入口会暂时禁用；分组切换需要重新读取素材库，因此与工作区切换一样，需等当前任务结束。当前没有任务队列。

任务使用启动时的参数与设置；中途修改不会改变批量索引剩余素材的选项，也不会改变正在生成的片段。若你在等待预览或首帧时换了选择/时间范围，旧结果不会覆盖新输入，待任务完成后可重新生成。保存其他设置不会清空正在查看的检索结果。

## 4. 人物抠像

1. 进入“自动抠像”，选视频或从检索结果送入。
2. 用“分钟:秒:帧”设置起止点，例如 `01:23:05`，点击“读取片段首帧”。目标必须在这个首帧中出现。
3. 选择一种提示方式。
4. 选择输出目录以及可选 MOV / AE 输出，点击“开始抠像”。

起点包含在输出中，终点不包含。例如24fps素材从 `00:00:23` 到 `00:01:00` 只输出第23帧。帧号从0开始，秒为00–59，分钟可超过59。仍可输入小数秒，读取首帧或开始抠像时会四舍五入到最近帧，并回填标准时间码。界面会显示帧率、编号范围和选中帧数；媒体未提供总帧数时标为估计，最终解码必须满足选中帧数才继续处理。

时间码采用非丢帧编号：23.976fps按24帧编号，29.97fps按30帧编号，帧数部分分别为00–23和00–29。因此23.976fps的 `01:00:00` 是第1440帧，约为实际60.06秒。抠像和首帧预览使用相同的源解码帧号；定位较后画面需要先解码前面的帧，读取首帧可能比按秒定位慢。

| 提示方式 | 输入要求 |
| --- | --- |
| 首帧蒙版 | 与首帧完整画布同尺寸；透明 PNG 的不透明区域或黑白蒙版白色区域表示保留；支持 PNG/BMP/TIF/TIFF |
| 像素框 | `[左, 上, 右, 下]`，是原图像素坐标，不是缩放预览中的坐标；框须覆盖目标且不能越界 |
| 语言描述 | 如“左侧蓝色长发、穿白色校服的女孩”；由 OpenAI 定位首帧目标框，再交给本地 SAM |
| 人物参考图 | PNG/JPEG/WebP，最大20MB；由 OpenAI 对照首帧定位人物 |

蒙版不能是裁切后的单独小图，不能全黑、全白，也不能把无透明背景的彩色参考图当蒙版。以首帧蒙版或人工框提示运行时不调用 OpenAI。

建议从2–10秒短片段开始。单次上限为120秒、3600帧、约884万像素且任一边不超过4096像素。默认每32帧分块跟踪，以减少内存占用；分块衔接、切镜、目标离场、遮挡、发丝和半透明特效可能需要人工修补。它是人物分割工具，不保证自动产生精细运动模糊 alpha。

## 5. 输出与 After Effects

每次成功抠像生成独立目录，不覆盖已有结果：

| 输出 | 用法 |
| --- | --- |
| `rgba/` | 透明 PNG 序列；像素结果的主要依据 |
| `masks/` | 同步灰度蒙版，便于继续修补 |
| `source_frames/` | 同步原始画面 PNG 序列，AE路径图层的素材来源 |
| `cutout_alpha.mov` | 可选 ProRes 4444，包含 alpha；普通播放器可能不能正确展示透明区域 |
| `preview_checkerboard.mp4` | 棋盘背景预览，便于检查边缘；它本身没有透明通道 |
| `import_cutout.jsx` | 可选 AE 逐帧路径脚本 |
| `manifest.json` | 完成标记及来源、时间、模型、输出警告记录 |
| `INCOMPLETE.txt` | 任务中断或失败，不能把该目录视为完整交付 |

抠像输出视频和棋盘预览不含音轨。选中范围按源视频解码顺序保留每一帧，再以平均帧率播放为固定帧率输出；VFR源的原始时间戳不会保留。`manifest.json` 记录 `start_frame`、`end_frame`（不含）、时间码、帧数和有理数帧率；其中秒数由帧号除以平均帧率计算。

在 AE 中可通过“文件 → 脚本 → 运行脚本文件”打开 JSX；或在本工具中配置 AfterFX 路径后点击“发送到 AE”。脚本在当前合成播放头位置新增视频序列图层，写入逐帧 HOLD 路径关键帧；没有活动合成时创建合成，必要时延长合成以容纳片段，不自动保存工程。

JSX 引用 `source_frames` 的绝对路径，导入前请保持原输出位置和完整目录。AE路径是二值轮廓近似，不保留所有半透明边缘；复杂轮廓超过上限时会明确提示 AE 未导出，PNG/MOV仍保留。PSD 图层及矢量路径序列暂不支持。详细限制见[抠像边界](抠像边界.md)。

## 6. 命令行模式

无需打开桌面界面即可调用全部核心处理功能。根目录 `MADSearcher-CLI.cmd` 使用项目虚拟环境；也可直接执行 `.venv\Scripts\python.exe -u scripts\cli.py`。每条命令输出UTF-8 NDJSON：一行一个进度、结果或错误事件。成功退出码为0，业务失败为1，命令参数语法错误为2，Ctrl+C中断为130。

```powershell
Set-Location 'E:\MADSearcher\MADSearcherTool'
.\MADSearcher-CLI.cmd --help
.\MADSearcher-CLI.cmd cutout.run --help
```

Windows PowerShell 5.1 如出现管道中文乱码，可在当前会话设置：

```powershell
$OutputEncoding = [System.Text.UTF8Encoding]::new($false)
[Console]::OutputEncoding = $OutputEncoding
```

### 分组、索引与查询

```powershell
.\MADSearcher-CLI.cmd group.create --name 'MyGO' --description '角色名称、别名与外观说明'
.\MADSearcher-CLI.cmd group.list

# 将占位文字替换为上一条返回的 data.id。
$groupId = '分组ID'
.\MADSearcher-CLI.cmd video.add --group-id $groupId --paths 'E:\做MAD\素材\MYGO\MyGO-01.mp4'
.\MADSearcher-CLI.cmd video.list --group-id $groupId

# 从 videos 数组中取得素材 id。
$videoId = '素材ID'
.\MADSearcher-CLI.cmd index.run --video-id $videoId --subtitle-path '.\字幕\MyGO-01.ass' --subtitle-offset 0
.\MADSearcher-CLI.cmd search.run --group-id $groupId --query '祥子 电车' --limit 20
```

如果没有字幕，索引时使用 `--transcribe --language ja`。`--visual` 明确启用画面分析和向量；`--semantic` 明确启用字幕向量。仅配置密钥而不加这两个索引参数，仍使用本地字幕关键词索引。

CLI 默认读取桌面设置及已保存的API Key。可用 `--settings 路径.json` 指定独立设置，字段支持worker的snake_case或桌面的PascalCase，密钥字段为 `api_key` 或 `ApiKey`。若进程中存在 `OPENAI_API_KEY`，其值优先于文件设置，包括显式空值。CLI不提供 `--api-key` 参数，也不改写设置文件。原始 `request` 入口使用请求中的settings，不自动合并桌面配置。

```powershell
# 已在桌面保存key时可省略这行；需要临时覆盖时在自己的会话中填写。
$env:OPENAI_API_KEY = ''

# 配好密钥后才执行以下云端操作：
.\MADSearcher-CLI.cmd index.run --video-id $videoId --subtitle-path '.\字幕\MyGO-01.ass' --visual
.\MADSearcher-CLI.cmd search.run --group-id $groupId --query '车站等人的女孩' --semantic
```

### 抠像与导出

```powershell
.\MADSearcher-CLI.cmd video.probe --path 'E:\做MAD\素材\MYGO\MyGO-01.mp4'
.\MADSearcher-CLI.cmd video.frame --path 'E:\做MAD\素材\MYGO\MyGO-01.mp4' --time 100
.\MADSearcher-CLI.cmd preview.make --path 'E:\做MAD\素材\MYGO\MyGO-01.mp4' --start 100 --end 105
.\MADSearcher-CLI.cmd clip.export --path 'E:\做MAD\素材\MYGO\MyGO-01.mp4' --start 100 --end 105 --output-dir '.\workspace\exports'

.\MADSearcher-CLI.cmd cutout.run --path '.\片段.mp4' --start 0 --end 3 --prompt-mode mask --mask-path '.\首帧蒙版.png' --device cuda --output-dir '.\workspace\exports'

# 框坐标必须依据实际首帧尺寸填写，下面仅演示参数格式。
.\MADSearcher-CLI.cmd cutout.run --path '.\片段.mp4' --start 0 --end 3 --prompt-mode box --box 100 50 400 600 --device cuda

# 先解析时间码并查看起止帧号，不加载 SAM 或请求云端。
.\MADSearcher-CLI.cmd cutout.range --path '.\片段.mp4' --start '00:00:00' --end '00:01:05'
.\MADSearcher-CLI.cmd cutout.run --path '.\片段.mp4' --start '00:00:00' --end '00:01:05' --prompt-mode mask --mask-path '.\首帧蒙版.png'

# 按源视频帧号取首帧，并只处理第24至第47帧（共24帧）。蒙版应对应刚取出的第24帧。
.\MADSearcher-CLI.cmd video.frame --path '.\片段.mp4' --frame-index 24
.\MADSearcher-CLI.cmd cutout.run --path '.\片段.mp4' --start-frame 24 --end-frame 48 --prompt-mode mask --mask-path '.\第24帧蒙版.png'
```

`cutout.range` 与 `cutout.run` 的 `start/end` 均接受时间码或小数秒。显式帧号 `start_frame/end_frame` 必须同时提供，不能与 `start/end` 混用；`video.frame` 的 `--frame-index` 也不能与 `--time` 混用。检索页的预览和 MP4 裁剪仍使用秒数。

文字模式使用 `--prompt-mode text --prompt '人物外观与位置'`；参考图模式使用 `--prompt-mode reference --reference-path '.\人物.png'`。默认生成MOV与AE脚本，可用 `--no-export-video` 或 `--no-export-ae` 关闭。未指定导出目录时使用当前工作区的 `exports`。

```powershell
.\MADSearcher-CLI.cmd ae.send --script-path '.\workspace\exports\某次任务\import_cutout.jsx' --afterfx-path 'C:\你的AE安装目录\AfterFX.exe'
```

`ae.send` 返回 `dispatched:true` 只表示已派发，不代表AE完成执行。此命令会实际启动/交接AE；本轮没有运行它做测试。

### JSON 与自动化调用

复杂参数可放入UTF-8 JSON文件，避免命令行引号问题：

```json
{
  "path": "E:/素材/片段.mp4",
  "start": 0,
  "end": 3,
  "prompt_mode": "mask",
  "mask_path": "E:/素材/首帧蒙版.png",
  "export_video": true,
  "export_ae": false
}
```

```powershell
.\MADSearcher-CLI.cmd cutout.run --params-file '.\任务参数.json' --device cuda
```

显式命令参数优先于参数文件。除完整原始请求入口 `request` 外，所有业务子命令也接受 `--workspace`、`--settings`、`--ffmpeg-path`、`--ffprobe-path`、`--sam-checkpoint`、`--sam-config`、`--device`、`--vision-model`、`--embedding-model`、`--whisper-model`、`--whisper-device`、`--afterfx-path`。`request` 的配置与参数直接写在请求对象中。

完整原始协议请求使用 `request --request-file 请求.json`，或 `request --request-file -` 从标准输入读取。请求结构见[设计文档](设计文档.md)。真实密钥可以保存在被Git忽略的本地设置中；不要将包含密钥的设置或请求文件提交到版本库。脚本也可通过环境变量或本次stdin传递。

完整命令清单：

| 类别 | 命令 |
| --- | --- |
| 环境 | `system.check` |
| 分组 | `group.list` / `group.create` / `group.update` / `group.delete` |
| 素材 | `video.list` / `video.add` / `video.remove` / `video.probe` / `video.frame` |
| 检索 | `index.run` / `search.run` |
| 抠像范围 | `cutout.range` |
| 媒体输出 | `preview.make` / `clip.export` / `cutout.run` |
| AE交接 | `ae.send` |
| 原始协议 | `request` |

批量索引可先用 `video.list` 取得组内各素材ID，再逐个调用 `index.run`。删除分组或素材记录不会删除原视频，但会移除相应索引；应确认ID后执行。

## 7. 常见问题

| 提示或现象 | 处理方式 |
| --- | --- |
| 找不到 Python / FFmpeg | 检查设置中的完整路径；Python应指向项目虚拟环境 |
| 找不到 SAM / 权重 | 运行 `setup.ps1 -WithSam`，填写tiny权重及对应配置 |
| CUDA不可用或内存不足 | 确认安装CUDA版PyTorch和NVIDIA驱动；关闭占用显存的软件，裁短/缩小片段，或选择CPU |
| 字幕索引不能找到某个场景 | 外挂字幕没有记录画面内容；需要显式建立画面索引 |
| 修改字幕后没有旧结果 | 旧索引被标记为变化，重新索引即可 |
| 语义检索无兼容向量 | 使用相同embedding模型重新索引；CLI会明确提示是否降级关键词匹配 |
| OpenAI 401 / 403 / 404 / 429 | 分别检查密钥、权限、模型名称、额度或频率；错误不会伪造成成功结果 |
| 模型下载网络失败 | 检查网络/代理；安装时可在适用情况下用 `-Direct`，Whisper也可填本地模型目录 |
| AE导出未生成或导入失败 | 查看manifest警告、轮廓复杂度、AfterFX路径及source_frames是否仍在原位置 |
| 取消后有未完成目录 | `INCOMPLETE.txt` 表示结果不完整；重新运行会生成新的输出目录，不覆盖原素材 |

使用和测试建议可继续补充到需求/测试文档；当前未自动启动后续验收。
