# MADSearcher 使用说明

当前为 `v0.1.0` 基线之后的 `dev` 开发版，程序内部版本号仍为1.0.0。项目目录：`E:\MADSearcher\MADSearcherTool`。

本工具提供两个核心流程：从大量动画素材中定位镜头，以及将短片段中的人物分离为透明素材。它不替代剪辑软件，也不自动完成一支 MAD。当前按照用户要求暂停新增及回归测试，以下说明依据已实现的接口与界面编写；验收状态见[验收记录](验收记录.md)。

## 1. 安装与启动

### 当前电脑

已在项目内准备 `.venv`、SAM 2.1 tiny 权重和 CUDA 版 PyTorch。直接打开：

```text
E:\MADSearcher\MADSearcherTool\artifacts\app\MADSearcher.exe
```

当前开发版包含镜头分段与动态采样、独立台词检索、AE三种导出、缓存清理及持久缩略图，发布位置为 `artifacts/app`。请从上面的路径启动新版；此前的 `artifacts/character-update` 目录保留旧发布版本。自行重新发布前先关闭目标目录中运行的程序。

也可双击 `MADSearcher.cmd`。此入口会执行 Release 编译，需要 .NET SDK；直接运行已发布 EXE 只需要对应的 .NET Desktop Runtime。发布目录依赖项目中的 `worker`、`.venv` 和模型文件，不能只复制一个 EXE 到别处。

### 新电脑或重新准备环境

先安装 Windows 版 .NET 9 SDK、Python 3.10 或更高版本，以及 FFmpeg / FFprobe。当前实现验证过的 Python 基线是 3.10，模型依赖在不同 Python 版本上仍需兼容的 wheel。

在 PowerShell 中进入项目：

```powershell
Set-Location 'E:\MADSearcher\MADSearcherTool'
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\setup.ps1
```

上面只准备基础依赖并编译界面。按需要增加组件：

```powershell
# SAM + NVIDIA GPU 推理
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\setup.ps1 -WithSam -Cuda

# SAM CPU 推理及本地多语言转录
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\setup.ps1 -WithSam -WithWhisper
```

| 参数 | 含义 |
| --- | --- |
| `-WithSam` | 安装 PyTorch、SAM 2 和官方 tiny 权重；下载量较大 |
| `-Cuda` | 与 `-WithSam` 合用，选择 CUDA 12.4 版 PyTorch；需要 NVIDIA GPU 与兼容驱动 |
| `-WithWhisper` | 安装 faster-whisper；语音模型在首次转录时下载 |
| `-Python '完整路径\python.exe'` | 指定用于创建虚拟环境的 Python |
| `-Direct` | 本次安装进程使用直连；适用于本机代理失效，不修改全局代理配置 |

安装目录默认都在项目中。`.venv`、`models`、`workspace`、`artifacts` 不提交到 Git。当前本机 CUDA wheel 约 2.5 GB，SAM tiny 权重约 156 MB，安装及视频帧缓存还需额外磁盘空间。

## 2. 首次设置

点击左下角“设置与环境”：

| 设置 | 建议或用途 |
| --- | --- |
| Python | `E:\MADSearcher\MADSearcherTool\.venv\Scripts\python.exe`；本机存在时自动选用 |
| FFmpeg / FFprobe | 可填 PATH 中的命令名，或对应 `.exe` 的完整路径 |
| 工作区 | 默认项目下 `workspace`；桌面端要求位于项目目录内 |
| API Key | 默认空；在密码框填写后点击“保存设置”，以明文保存在本地，重启后自动恢复 |
| 视觉模型 | 默认 `gpt-4.1-mini`；需账号实际拥有该模型权限 |
| Embedding 模型 | 默认 `text-embedding-3-small`；更换后应重新建立向量索引 |
| SAM 权重 | `models\sam2.1_hiera_tiny.pt` 的完整路径 |
| SAM 配置 | tiny 对应 `configs/sam2.1/sam2.1_hiera_t.yaml` |
| SAM 计算设备 | 本机 RTX 3060 已准备 CUDA 环境，可选择 `cuda`；不支持 GPU 时选择 `cpu` |
| Whisper 模型 / 设备 | 默认 `small` / `cpu`；可填写已下载的模型目录，CUDA 转录另需兼容的 cuDNN/cuBLAS 环境 |
| After Effects | 需要直接交接时填写安装目录中的 `AfterFX.exe` 完整路径 |

点击“保存设置”。设置与API Key保存在项目的 `workspace/settings.json`，该目录已被Git忽略。清空密码框后再次保存即可删除已保存的key。环境诊断用于显示依赖状态，密钥存在不代表 API 权限或余额已验证。

仅填写密钥不会自动发送素材。以下操作会调用 OpenAI：AI画面分析、字幕语义索引、语义查询、文字/参考图定位。它们会发送采样图或文字，不上传整集原视频；API费用由所填密钥的账户承担。

## 3. 找镜头

### 创建分组并导入

1. 打开“片段检索”，在素材库点击“新建”，每部动画建立一个分组。
2. 在“新建 / 编辑动画分组”填写作品背景，并用“添加角色”保存角色资料。姓名、别名、作品资料、身份说明、外观特点和参考图均可不填；每组最多30个角色，每人最多3张静态PNG/JPEG/WebP参考图。仅填写资料不会自动建立出镜关联，需要之后启用AI画面索引。
3. 点击“导入 MP4”，可一次选多个文件。程序引用原路径，不复制或改写原片；同组的重复路径会跳过。
4. 选中一个素材，再配置它的字幕与索引选项。

导入的MP4列表使用像素连续滚动。素材库中的作品背景最多显示约5行高度，超出时可在背景区域内用滚轮或右侧滚动条查看全文；分组统计信息保持可见。切换或重新载入分组后，背景从顶部显示，空背景不占用该区域。

### 编辑角色资料

左侧选择角色，右侧填写已知资料；别名每行一个，可直接按Enter换行，输入时保留空行，点击“保存分组”时才去除空项、首尾空格及重复别名。参考图宜包含清楚可辨的发型、配饰或面部特征，可添加不同造型。完全空白的角色可以保存，但不会参与模型判断。每张图片最多20MB、2500万像素。

点击“保存分组”后，参考图被复制到工作区的 `characters/references`，原文件保持原样；取消编辑不改变已保存内容。预览不支持的图片编码仍可显示路径，最终可用性由保存时的图片校验决定。移除图片或角色只解除引用，不自动删除工作区中的图片文件。

修改背景或角色资料后，应重新索引相关素材；角色变动会使旧视觉索引失效。首次打开旧数据库会在工作区 `backups` 下创建升级前备份。迁移及角色识别效果尚待功能验收。

### 选择索引方式

| 方式 | 能力 | 依赖 |
| --- | --- | --- |
| 外挂字幕关键词 | 找字幕中出现的台词、名字和文字线索 | SRT / ASS / VTT；不需要 API key |
| 本地语音识别 | 没有字幕时生成带时间轴的原语文字 | faster-whisper 和语音模型 |
| 建立字幕语义索引 | 对单条字幕及相邻短上下文建立独立向量，支持近义或跨语言线索 | 显式勾选该选项及 OpenAI key |
| AI分析画面与情节 | 对每段动态选取的1～6张采样图建立描述、关联已保存角色，并生成语义向量 | 显式勾选该选项及 OpenAI key |

外挂字幕必须与当前选中的素材对应。正的“字幕偏移”让字幕向后推迟，负数提前；单位为秒。当前素材保存成功的索引配置会记住字幕路径和偏移。字幕必须有有效时间轴；允许起止时间相等，零时长台词按该时间点归入对应索引窗口。乱码、倒置时间和完全越界会给出提示。

ASS/SSA会先过滤绘图坐标、去重显示层，并合并连续的重复特效文字，保留正常对白及实际时间；20000条限制按清理、分行和去重后的有效字幕计算。原字幕不改写，文件上限仍为20MiB。已建立的旧ASS台词索引可点击“仅补建选中素材台词索引”更新，无须重跑视觉分析；详细规则和清理日志见[台词检索与补建](台词检索与补建.md#ass特效字幕与条数上限)。

若无字幕，可勾选本地语音识别并选择“自动”、日语、中文等语言。首次运行可能下载模型。若同时提供外挂字幕和勾选转录，程序优先使用外挂字幕。角色名字、歌词和背景音乐处的转录仍需核对。

点击“建立 / 更新选中素材索引”。默认选择“按镜头切换”，灵敏度为中，长镜头上限为20秒。超过上限会继续细分，保留原镜头归属。也可选择“固定时长”（默认8秒）。所有时长输入范围2–60秒。索引完成后可重复查询，不必每次重新分析。CLI对应 `--segmentation shot --shot-max-seconds 20 --scene-sensitivity medium`；只传旧参数 `--segment-seconds 8` 仍使用固定时长。

开启AI画面分析时，每段都会发送已填写的角色资料与全部参考图。索引外发图片长边最多512像素，原图不改写；缩图缓存节省本地处理，但不代表后续请求不再发送图片。角色/图片数量越多，输入成本越高；512像素下的小脸、配饰可能难以识别。单独开启“建立字幕语义索引”只发送字幕，不发送角色图、不建立出镜关联。

“索引组内全部素材”逐个处理本组视频：选中素材使用当前表单，其他素材使用各自已保存的字幕路径和偏移，AI及转录选项沿用当前勾选状态。没有字幕又未选择转录/画面分析的素材会被阻止；建议先为各集分别绑定字幕。

### 查询与预览

搜索框右侧可选“综合 / 台词 / 画面情节”，默认综合。找原文或不同译文的名台词时，建议选“台词”并勾选“语义检索”。它直接比较查询与字幕，不混入画面描述；没有启用语义时仍可找原文和字面近似内容。

已有素材第一次使用独立台词检索，需要选中视频、确认字幕路径及偏移，勾选“建立字幕语义索引（OpenAI）”，再点击“仅补建选中素材台词索引”。该操作不重做视觉分析，也不转录音频；复用已保存文本向量，仅补缺失项。素材卡片会显示台词条数与语义状态。新建完整索引时也会保存独立台词记录。迁移、费用与旧片段时码说明见[台词检索与补建](台词检索与补建.md)。

在综合或画面情节模式，输入“祥子”“电车”“乐队”“在车站等人”等关键词，或直接输入“长崎素世请求丰川祥子不要离开”。查询只在当前分组内进行，会从句子中提取已保存的姓名和别名，无须在中文姓名前后添加空格。较长名称优先匹配；同名或同别名对应多个角色时保留歧义并提示。单字别名只匹配独立词项，英文名称检查词边界。

在综合或画面情节模式只输入已保存的姓名或别名时，程序使用本地索引中的出镜关联及姓名文字提及，**不请求查询向量，也不需要API Key**。清晰出镜证据优先于待确认关联，姓名文字提及单独标记；若索引中只有字幕而没有视觉关联，只能找到文字中提及的人物。台词模式按原始查询检索字幕，不进行姓名改写。

姓名加情节的查询会保留原句，同时生成去除姓名的情节查询，以及根据已填写外观替换姓名的补充查询。例如角色外观分别填写“棕发女孩”“蓝发女孩”时，会补充“（棕发女孩）请求（蓝发女孩）不要离开”，保留谁请求谁的语序；资料缺失时不会编造外观。勾选“语义检索”后，相应素材须已有兼容模型的向量，最多三路查询合并请求并缓存。关闭语义时按本地文字与人物证据查询；缺少密钥或向量时会提示降级。普通无角色查询继续使用文字与语义相关度。

组合查询以情节相关度为主，人物出镜证据只作有限加分。没有识别出角色身份但情节相关的片段仍能入选；纯姓名查询则优先出镜证据。结果上方显示识别到的查询角色、情节与实际参与的外观语义通道，悬停匹配说明可查看评分构成。分数用于排序，不是匹配正确率；相邻镜头的角色证据也不能证明同框或动作关系。

仅应用第13项查询与排序更新，**不需要重建已有有效索引**，也不会重新发送视频采样图；原素材、角色资料或模型变更导致的索引失效规则仍然适用。第12项人物识别误差尚未处理，错误关联仍可能影响人物加分。本次功能测试继续延期，检索效果待按后续测试文档验证。详细规则、查询缓存与边界见[姓名查询与排序](姓名查询与排序.md)。

结果会显示文件名、起止时间、缩略图和命中文字/描述，卡片列表按像素连续滚动。仅字幕索引查不到画面中没有被字幕提及的电车或人物，是能力边界，不代表原片没有相应镜头。未知角色、复杂情节和短暂闪现也可能漏检。角色关联结果显示“画面角色”，不够确定的匹配标为“待确认”；鼠标悬停该行可查看采样画面依据及原始窗口范围。字幕点名仍可能命中字幕关键词，但这不等于角色在画面中出现。

选中结果后点击“生成 / 更新预览”。可修改起止秒数、重新预览、导出 MP4，或“送到自动抠像”。镜头索引结果默认保留切镜边界；“扩展前后镜头”可包含前后各一个镜头，“恢复命中范围”恢复原范围，之后重新生成预览。扩展不会改变人物出镜证据。预览会转成便于播放的 H.264 MP4，源视频为10bit H.264等编码时尤其有用。单次预览最长5分钟。生成的预览是缓存文件，不改变原片。

按时长动态采样：2秒以内1张、2～5秒2张、5～10秒3张、更长片段4～6张；近似重复图片会减少。镜头增多可能增加请求总数及重复发送参考图的成本，不能保证费用降低。检测和采样缓存与角色资料独立，修改角色后可复用。详细规则、缓存路径和新日志字段见[镜头分段与动态采样](镜头分段与动态采样.md)。

取消会停止当前处理；重做索引只有全部成功后才替换数据库中的旧索引。原视频或字幕改变后，相应索引需要更新；分组说明、角色资料或参考图改变会使旧视觉索引失效，独立台词索引按自身文件来源校验，仍可继续查询。

### 查看索引耗时

点击“打开索引耗时日志”。默认目录是 `E:\MADSearcher\MADSearcherTool\workspace\logs\index`；每个视频、每次索引各生成 `.jsonl` 逐条日志和 `.summary.json` 汇总。开始时进度给出具体日志路径，运行中也可打开目录。

先看汇总的 `status` 和 `total_ms`，再按 `self_ms` 查看耗时最多的模块。抽帧、图片缩放、视觉请求、向量请求、ASR、检查点及数据库提交都有独立阶段；`inclusive_ms`包含子步骤，不能把各层总时间重复相加。日志还记录API实际返回的token、缓存token与重试等待，可以区分模型等待和本地处理耗时。

取消时进程被终止，可能没有最终汇总；查看JSONL末尾的 `stage_start` 可以定位当时正在执行的阶段，没有 `run_end` 不能视为完成。日志不会写入密钥、完整字幕、提示词正文或图片base64。字段、阶段名称及完整提示词见[角色索引技术路线与提示词](角色索引技术路线与提示词.md)。

角色关联再次报错时，优先查看最新 `.summary.json` 的 `validation_failure`：`reason`指出具体原因，`issues`包含字段位置，`matches_preview`给出ID、依据长度及帧号等诊断，`segment`和起止秒数定位片段。新日志带 `log_schema_version: 2`；同样的诊断也会立即写入JSONL的 `validation_failed` 事件。同一版本、素材、资料及设置不变时，成功片段可复用。第11项升级为索引配置版本4，旧索引仍可查询，重建时使用新缓存，不直接复用版本3的AI检查点。

### 任务进行时的操作

索引、检索、转码或抠像进行时，可以切换页面、滚动、选择现有素材和结果、播放已有预览、编辑其他表单及保存设置。新增处理任务的入口会暂时禁用；分组切换需要重新读取素材库，因此与工作区切换一样，需等当前任务结束。当前没有任务队列。

任务使用启动时的参数与设置；中途修改不会改变批量索引剩余素材的选项，也不会改变正在生成的片段。若你在等待预览或首帧时换了选择/时间范围，旧结果不会覆盖新输入，待任务完成后可重新生成。保存其他设置不会清空正在查看的检索结果。

## 4. 人物抠像

1. 进入“自动抠像”，选视频或从检索结果送入。
2. 在右侧原视频时间线上拖动定位，等待画面加载后设置开始/结束；也可用“分钟:秒:帧”输入，例如 `01:23:05`，点击“载入预览 / 回到起点”。目标必须出现在抠像起点的画面中。
3. 选择一种提示方式。
4. 选择输出目录以及可选 MOV / AE 输出，点击“开始抠像”。

起点包含在输出中，终点不包含。例如24fps素材从 `00:00:23` 到 `00:01:00` 只输出第23帧。帧号从0开始，秒为00–59，分钟可超过59。仍可输入小数秒，载入预览或开始抠像时会四舍五入到最近帧，并回填标准时间码。界面会显示帧率、编号范围和选中帧数；媒体未提供总帧数时标为估计，最终解码必须满足选中帧数才继续处理。

时间码采用非丢帧编号：23.976fps按24帧编号，29.97fps按30帧编号，帧数部分分别为00–23和00–29。因此23.976fps的 `01:00:00` 是第1440帧，约为实际60.06秒。抠像和首帧预览使用相同的源解码帧号；定位较后画面需要先解码前面的帧，读取首帧可能比按秒定位慢。

### 时间线、预览和缓存

原视频与抠像结果在两个独立面板中显示，点击标题箭头可分别折叠。结果面板使用完成任务的RGBA帧序列，棋盘表示透明区域；结果下方保留任务的源文件和范围，结果帧号从0开始，并显示对应的源帧号。修改左侧输入不会改写已有结果或正在运行的任务。

| 操作 | 使用方法 |
| --- | --- |
| 定位 | 点击或拖动时间线指针；首次到未缓存位置可能需要等待，旧画面会变暗并显示加载提示 |
| 播放/暂停 | 点击播放按钮，或让焦点位于预览面板后按空格；左侧文字输入框中的空格正常输入 |
| 精确选帧 | 左/右方向键或“◀ 帧”“帧 ▶”按钮，每次移动一帧 |
| 设置开始 | 在原视频画面加载好后点“设为开始”或按I；同时更新左侧起点 |
| 设置结束 | 点“设为结束”或按O，**包含当前帧**；左侧终点自动写成下一帧边界 |
| 精细定位 | ＋/－或Ctrl+滚轮缩放时间线；“全片”恢复完整范围，“回到起点”返回有效选区起点 |
| 缓存状态 | 青色条表示已缓存画面，蓝色条和边界线表示有效抠像范围；无效范围会显示原因 |
| 加载失败 | 检查素材、FFmpeg设置后使用“重试加载”；修改FFmpeg路径后需重新载入预览 |

例如拖到20秒，第一帧就绪后即可查看，后台继续准备未来约5秒；播放到22秒时继续向27秒预取，并保留走过的约2秒供回看。播放前至少准备约半秒连续画面，缓冲不足时停住等待，补足后继续。连续播放复用同一个解码进程；首次跳到较远位置仍按源帧序从头解码，可能等待较长时间。快速拖动会合并请求，过期解码不会覆盖新的位置。

缓存只驻留内存，每个面板的缓存像素不超过128MiB，预览长边最多640像素，并按帧率进一步缩小以控制占用。已经淘汰的画面需重新加载；切换视频或关闭程序清空缓存。折叠、离开页面或操作另一个预览时暂停当前播放/解码，保留现有缓存。两个面板均为**无声画面预览**，按平均帧率播放；原图、蒙版坐标及抠像输出精度不受预览缩放影响。

改变开始点后，请确认首帧蒙版仍对应新起点。设置边界不会自动移动另一端，倒置、超出视频或超过120秒/3600帧时会显示范围错误。范围最终仍由worker校验，播放指针本身不改变抠像输入。

| 提示方式 | 输入要求 |
| --- | --- |
| 首帧蒙版 | 与首帧完整画布同尺寸；透明 PNG 的不透明区域或黑白蒙版白色区域表示保留；支持 PNG/BMP/TIF/TIFF |
| 像素框 | `[左, 上, 右, 下]`，是原图像素坐标，不是缩放预览中的坐标；框须覆盖目标且不能越界 |
| 语言描述 | 如“左侧蓝色长发、穿白色校服的女孩”；由 OpenAI 定位首帧目标框，再交给本地 SAM |
| 人物参考图 | PNG/JPEG/WebP，最大20MB；由 OpenAI 对照首帧定位人物 |

蒙版不能是裁切后的单独小图，不能全黑、全白，也不能把无透明背景的彩色参考图当蒙版。以首帧蒙版或人工框提示运行时不调用 OpenAI。文字/参考图定位发出的首帧和参考图保留方向校正后的原始分辨率，采用JPEG质量95编码和高细节请求，不应用512像素上限；例如1920×1080首帧仍以1920×1080上传。模型返回归一化框后映射回原始坐标，本地SAM的输入帧和蒙版使用原始尺寸。外部模型仍可能按自身规则处理或缩放图像。界面预览的640像素缓存上限只影响显示，不影响上传和抠像。

建议从2–10秒短片段开始。单次上限为120秒、3600帧、约884万像素且任一边不超过4096像素。默认每32帧分块跟踪，以减少内存占用；分块衔接、切镜、目标离场、遮挡、发丝和半透明特效可能需要人工修补。它是人物分割工具，不保证自动产生精细运动模糊 alpha。

## 5. 输出与 After Effects

每次成功抠像生成独立目录，不覆盖已有结果：

| 输出 | 用法 |
| --- | --- |
| `rgba/` | 透明 PNG 序列；像素结果的主要依据 |
| `masks/` | 同步灰度蒙版，便于继续修补 |
| `source_frames/` | 同步完整原画 PNG 序列，AE遮罩/矢量方式的素材来源 |
| `cutout_alpha.mov` | 可选 ProRes 4444，包含 alpha；普通播放器可能不能正确展示透明区域 |
| `preview_checkerboard.mp4` | 棋盘背景预览，便于检查边缘；它本身没有透明通道 |
| `ae_exports/ae_*/` | 每次独立的AE脚本、导出报告与日志；旧版根目录import_cutout.jsx保留 |
| `manifest.json` | 完成标记及来源、时间、模型、输出警告记录 |
| `INCOMPLETE.txt` | 任务中断或失败，不能把该目录视为完整交付 |

抠像输出视频和棋盘预览不含音轨。选中范围按源视频解码顺序保留每一帧，再以平均帧率播放为固定帧率输出；VFR源的原始时间戳不会保留。`manifest.json` 记录 `start_frame`、`end_frame`（不含）、时间码、帧数和有理数帧率；其中秒数由帧号除以平均帧率计算。

AE导出有“透明PNG序列”“原画＋独立Alpha遮罩”（默认）和“可编辑矢量路径”三种。前两种保留现有像素和透明度，默认遮罩方式对外只有一个人物合成；双击进入后，“01 整体边缘”在效果控件调柔化/收缩，“02 局部修补”双击后在补回或去除层画添加蒙版。补回直接显示真实原画，整体边缘默认均为0，最终效果在外层人物合成查看。内部原画已锁定并默认从时间线隐藏，无需手动连接Alpha。第三种为逐帧HOLD轮廓近似。矢量复杂度超限时明确改用像素遮罩，前两种不受轮廓节点数限制。

已有任务可在结果区点击“从已有结果补导出 AE…”，选择对应manifest.json，使用左侧所选方式重新生成脚本，无需重跑SAM、解码视频或调用模型。成功后确认实际方式/任务来源，再点击“发送到AE”，或在AE“文件 → 脚本 → 运行脚本文件”执行对应JSX。

已有JSX/AE合成不会自动更新图层关系。要使用彩色修补和整体边缘入口，需要重新补导出并导入新脚本（script_version=2）；旧合成及手工蒙版保留，必要时自行把新增修补蒙版复制到新合成对应图层。

新脚本创建原尺寸/帧率合成，再放入当前合成播放头处，不自动保存工程；相对路径支持完整任务目录一起移动。像素遮罩不会被强制简化；矢量路径每轮廓4096点等限制属于本工具资源保护。PSD序列暂不支持。具体的补导出、AE局部修补操作和日志见[AE导出与修补](AE导出与修补.md)，质量边界见[抠像边界](抠像边界.md)。

### 分组、索引与查询

```powershell
.\MADSearcher-CLI.cmd group.create --name 'MyGO' --description '作品背景，可留空'
.\MADSearcher-CLI.cmd group.list

# 将占位文字替换为上一条返回的 data.id。
$groupId = '分组ID'
.\MADSearcher-CLI.cmd video.add --group-id $groupId --paths 'E:\做MAD\素材\MYGO\MyGO-01.mp4'
.\MADSearcher-CLI.cmd video.list --group-id $groupId

# 从 videos 数组中取得素材 id。
$videoId = '素材ID'
.\MADSearcher-CLI.cmd index.run --video-id $videoId --subtitle-path '.\字幕\MyGO-01.ass' --subtitle-offset 0
.\MADSearcher-CLI.cmd search.run --group-id $groupId --query '祥子 电车' --limit 20
```

如果没有字幕，索引时使用 `--transcribe --language ja`。`--visual` 明确启用画面分析和向量；`--semantic` 明确启用字幕向量。仅配置密钥而不加这两个索引参数，仍使用本地字幕关键词索引。

CLI 默认读取桌面设置及已保存的API Key。可用 `--settings 路径.json` 指定独立设置，字段支持worker的snake_case或桌面的PascalCase，密钥字段为 `api_key` 或 `ApiKey`。若进程中存在 `OPENAI_API_KEY`，其值优先于文件设置，包括显式空值。CLI不提供 `--api-key` 参数，也不改写设置文件。原始 `request` 入口使用请求中的settings，不自动合并桌面配置。

```powershell
# 已在桌面保存key时可省略这行；需要临时覆盖时在自己的会话中填写。
$env:OPENAI_API_KEY = ''

# 配好密钥后才执行以下云端操作：
.\MADSearcher-CLI.cmd index.run --video-id $videoId --subtitle-path '.\字幕\MyGO-01.ass' --visual
.\MADSearcher-CLI.cmd search.run --group-id $groupId --query '车站等人的女孩' --semantic
```

### 用JSON维护角色列表

角色列表属于复杂参数，通过 `--params-file` 传入，例如将以下内容保存为工作区内的 `group.json`。创建时可省略角色ID，返回结果会包含分配的稳定ID；更新已有角色时保留其ID。

```json
{
  "name": "示例动画",
  "description": "作品背景，可留空",
  "characters": [
    {
      "name": "角色甲",
      "aliases": ["昵称甲"],
      "work_info": "角色的经历和关系，可留空",
      "identity": "身份说明，可留空",
      "appearance": "蓝色长发，星形发饰",
      "reference_images": ["E:/素材/角色甲.png"]
    },
    {}
  ]
}
```

```powershell
.\MADSearcher-CLI.cmd group.create --params-file '.\workspace\group.json'
# group.update同样支持此文件，额外指定实际分组ID。
.\MADSearcher-CLI.cmd group.update --group-id $groupId --params-file '.\workspace\group.json'
# 仅查看指定角色的关联片段，可不填query；先建立视觉索引。
.\MADSearcher-CLI.cmd search.run --group-id $groupId --character-id '实际角色ID'
```

`group.update`传入characters时替换整份角色列表，未列出的角色会被移除；省略此字段则保留现有角色，传 `[]` 则清空。不保留ID的卡片会被当作新角色；建议从 `group.list` 返回的资料编辑后再更新。

### 抠像与导出

```powershell
.\MADSearcher-CLI.cmd video.probe --path 'E:\做MAD\素材\MYGO\MyGO-01.mp4'
.\MADSearcher-CLI.cmd video.frame --path 'E:\做MAD\素材\MYGO\MyGO-01.mp4' --time 100
.\MADSearcher-CLI.cmd preview.make --path 'E:\做MAD\素材\MYGO\MyGO-01.mp4' --start 100 --end 105
.\MADSearcher-CLI.cmd clip.export --path 'E:\做MAD\素材\MYGO\MyGO-01.mp4' --start 100 --end 105 --output-dir '.\workspace\exports'

.\MADSearcher-CLI.cmd cutout.run --path '.\片段.mp4' --start 0 --end 3 --prompt-mode mask --mask-path '.\首帧蒙版.png' --device cuda --output-dir '.\workspace\exports'

# 框坐标必须依据实际首帧尺寸填写，下面仅演示参数格式。
.\MADSearcher-CLI.cmd cutout.run --path '.\片段.mp4' --start 0 --end 3 --prompt-mode box --box 100 50 400 600 --device cuda

# 先解析时间码并查看起止帧号，不加载 SAM 或请求云端。
.\MADSearcher-CLI.cmd cutout.range --path '.\片段.mp4' --start '00:00:00' --end '00:01:05'
.\MADSearcher-CLI.cmd cutout.run --path '.\片段.mp4' --start '00:00:00' --end '00:01:05' --prompt-mode mask --mask-path '.\首帧蒙版.png'

# 按源视频帧号取首帧，并只处理第24至第47帧（共24帧）。蒙版应对应刚取出的第24帧。
.\MADSearcher-CLI.cmd video.frame --path '.\片段.mp4' --frame-index 24
.\MADSearcher-CLI.cmd cutout.run --path '.\片段.mp4' --start-frame 24 --end-frame 48 --prompt-mode mask --mask-path '.\第24帧蒙版.png'
```

`cutout.range` 与 `cutout.run` 的 `start/end` 均接受时间码或小数秒。显式帧号 `start_frame/end_frame` 必须同时提供，不能与 `start/end` 混用；`video.frame` 的 `--frame-index` 也不能与 `--time` 混用。检索页的预览和 MP4 裁剪仍使用秒数。

文字模式使用 `--prompt-mode text --prompt '人物外观与位置'`；参考图模式使用 `--prompt-mode reference --reference-path '.\人物.png'`。默认生成MOV与AE脚本，AE方式默认matte，可选 `--ae-mode rgba` 或 `--ae-mode paths`；可用 `--no-export-video` 或 `--no-export-ae` 关闭自动输出。未指定导出目录时使用当前工作区的 `exports`。

```powershell
.\MADSearcher-CLI.cmd cutout.export_ae --manifest-path '.\workspace\exports\某次任务\manifest.json' --ae-mode matte
.\MADSearcher-CLI.cmd ae.send --script-path '.\workspace\exports\某次任务\ae_exports\某次导出\import_matte.jsx' --afterfx-path 'C:\你的AE安装目录\AfterFX.exe'
```

`ae.send` 返回 `dispatched:true` 只表示已派发，不代表AE完成执行。此命令会实际启动/交接AE；本轮没有运行它做测试。

## 7. 常见问题

### 缓存占用与索引目录

顶部“工具 → 删除缓存…”会先显示各类缓存、日志和备份的容量，确认后执行。清理保留已完成的数据库索引、角色参考图、模型及所有任务结果，未完成抠像任务也保留。新索引使用workspace/thumbnails中的长期缩略图；旧索引仍引用cache图片时，清理先复制图片并事务更新引用，再删除缓存，无需重新建立索引。向量缓存删除后已有索引仍可搜索，但后续请求或重建可能增加等待和接口费用。

“工具 → 打开索引目录”打开当前工作区并选中library.sqlite3；thumbnails与数据库位于同一目录。请使用程序清理入口，避免直接删除旧索引还在引用的cache图片。范围、异常及CLI用法见[缓存清理与索引资源](缓存清理与索引资源.md)。

### 其他问题

| 提示或现象 | 处理方式 |
| --- | --- |
| 找不到 Python / FFmpeg | 检查设置中的完整路径；Python应指向项目虚拟环境 |
| 找不到 SAM / 权重 | 运行 `setup.ps1 -WithSam`，填写tiny权重及对应配置 |
| CUDA不可用或内存不足 | 确认安装CUDA版PyTorch和NVIDIA驱动；关闭占用显存的软件，裁短/缩小片段，或选择CPU |
| 字幕索引不能找到某个场景 | 外挂字幕没有记录画面内容；需要显式建立画面索引 |
| 填写角色后用名字搜不到画面 | 保存资料后重新启用AI画面索引；只建字幕索引没有视觉身份关联，模型依据不足也可能不关联 |
| 修改字幕后没有旧结果 | 旧索引被标记为变化，重新索引即可 |
| 语义检索无兼容向量 | 使用相同embedding模型重新索引；CLI会明确提示是否降级关键词匹配 |
| OpenAI 401 / 403 / 404 / 429 | 分别检查密钥、权限、模型名称、额度或频率；错误不会伪造成成功结果 |
| 模型下载网络失败 | 检查网络/代理；安装时可在适用情况下用 `-Direct`，Whisper也可填本地模型目录 |
| AE导出未生成或导入失败 | 选择Alpha方式从已有manifest补导出；查看export_report.json、实际脚本和PNG序列完整性，AE中确认实际执行结果 |
| 取消后有未完成目录 | `INCOMPLETE.txt` 表示结果不完整；重新运行会生成新的输出目录，不覆盖原素材 |
